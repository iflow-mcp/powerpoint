MCP Market Introduction

The Model Context Protocol (MCP) is an open standard that enables seamless integration between language models and external tools. This PowerPoint MCP Server implements the protocol to provide powerful presentation creation capabilities directly from your AI assistant.

Flexible Slide Types

Create various slide layouts including title slides, content slides, comparison slides, and more.

Dynamic Charts

Automatically generate charts from data with intelligent chart type selection.

Data Tables

Easily add formatted tables to present structured data in your presentations.

AI Image Generation

Generate custom images using AI and include them directly in your slides.

Installation and Usage Guide

Prerequisites

  • Python 3.8 or higher
  • UV package manager
  • TogetherAI API key (for image generation)

Installation Steps

  1. Install UV

    On macOS/Linux:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    On Windows:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  2. Clone the Repository

    git clone https://github.com/iflow-mcp/powerpoint.git
cd powerpoint

  3. Install Dependencies

    uv sync

Configuration

An environment variable is required for image generation via TogetherAI:

  1. Register for an account at TogetherAI
  2. Obtain your API key
  3. Set the environment variable:
export TOGETHER_API_KEY="your_api_key_here"

Running the Server

Start the server with:

uv run powerpoint --folder-path /path/to/your/presentations

Claude Desktop Integration

To use with Claude Desktop, add the server to your configuration file:

On macOS: ~/Library/Application\ Support/Claude/claude_desktop_config.json

On Windows: %APPDATA%/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "powerpoint": {
      "command": "uv",
      "env": {
        "TOGETHER_API_KEY": "your_api_key_here"
      },
      "args": [
        "--directory",
        "/path/to/powerpoint",
        "run",
        "powerpoint",
        "--folder-path",
        "/path/to/decks_folder"
      ]
    }
  }
}

MCP Tools Detailed Explanation

create-presentation

Starts a new presentation with the given name.

Parameters:

  • name (string, required): Name of the presentation (without .pptx extension)

add-slide-title-only

Adds a title slide to the presentation.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • title (string, required): Title of the slide

add-slide-section-header

Adds a section header slide to the presentation.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • header (string, required): Section header title
  • subtitle (string, optional): Section header subtitle

add-slide-title-content

Adds a slide with title and content to the presentation.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • title (string, required): Title of the slide
  • content (string, required): Content/body text of the slide

Content formatting: Separate main points with a single carriage return. Make sub-points with tab character. Do not use bullet points, asterisks or dashes for points. Max main points is 4.

add-slide-comparison

Adds a comparison slide with title and two content sections.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • title (string, required): Title of the slide
  • left_side_title (string, required): Title of the left concept
  • left_side_content (string, required): Content of the left concept
  • right_side_title (string, required): Title of the right concept
  • right_side_content (string, required): Content of the right concept

add-slide-title-with-table

Adds a slide with title and a table containing the provided data.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • title (string, required): Title of the slide
  • data (object, required): Table data with headers and rows

Data structure:

{
  "headers": ["Column 1", "Column 2", "Column 3"],
  "rows": [
    ["Row 1 Col 1", "Row 1 Col 2", "Row 1 Col 3"],
    ["Row 2 Col 1", "Row 2 Col 2", "Row 2 Col 3"]
  ]
}

add-slide-title-with-chart

Adds a slide with title and a chart. The chart type is automatically selected based on the data structure.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • title (string, required): Title of the slide
  • data (object, required): Chart data structure

Data structure:

{
  "categories": ["Category 1", "Category 2", "Category 3"],
  "series": [
    {
      "name": "Series 1",
      "values": [10, 20, 30]
    },
    {
      "name": "Series 2",
      "values": [15, 25, 35]
    }
  ],
  "x_axis": "X-axis Title",
  "y_axis": "Y-axis Title"
}

add-slide-picture-with-caption

Adds a slide with a picture and caption.

Parameters:

  • presentation_name (string, required): Name of the presentation
  • title (string, required): Title of the slide
  • caption (string, required): Caption text to appear below the picture
  • image_path (string, required): Path to the image file to insert

open-presentation

Opens an existing presentation and saves a copy to a new file for backup.

Parameters:

  • presentation_name (string, required): Name of the presentation to open

save-presentation

Saves the presentation to a file. Always use this tool at the end of any process that has added slides to a presentation.

Parameters:

  • presentation_name (string, required): Name of the presentation to save

generate-and-save-image

Generates an image using a FLUX model and saves it to the specified path.

Parameters:

  • prompt (string, required): Description of the image to generate
  • file_name (string, required): Filename of the image (include .png extension)

Code Examples and Configuration

Basic Presentation Creation

Create a simple presentation with a title slide and content slide:

// 1. Create a new presentation
{
  "name": "my-presentation"
}

// 2. Add a title slide
{
  "presentation_name": "my-presentation",
  "title": "My Presentation Title"
}

// 3. Add a content slide
{
  "presentation_name": "my-presentation",
  "title": "Introduction",
  "content": "This is the first point\n\tThis is a sub-point\nThis is the second point"
}

// 4. Save the presentation
{
  "presentation_name": "my-presentation"
}

Working with Tables

Add a slide with a table:

{
  "presentation_name": "my-presentation",
  "title": "Sales Data",
  "data": {
    "headers": ["Month", "Revenue", "Expenses"],
    "rows": [
      ["January", 10000, 8000],
      ["February", 12000, 9000],
      ["March", 15000, 10000]
    ]
  }
}

Creating Charts

Add a slide with a chart:

{
  "presentation_name": "my-presentation",
  "title": "Quarterly Performance",
  "data": {
    "categories": ["Q1", "Q2", "Q3", "Q4"],
    "series": [
      {
        "name": "Revenue",
        "values": [10000, 12000, 15000, 18000]
      },
      {
        "name": "Expenses",
        "values": [8000, 9000, 10000, 11000]
      }
    ],
    "x_axis": "Quarter",
    "y_axis": "Amount ($)"
  }
}

Generating Images with AI

Generate and use an AI-created image:

// 1. Generate an image
{
  "prompt": "A beautiful landscape with mountains and a lake",
  "file_name": "landscape.png"
}

// 2. Add a slide with the image
{
  "presentation_name": "my-presentation",
  "title": "Beautiful Landscapes",
  "caption": "A scenic mountain landscape",
  "image_path": "landscape.png"
}

Frequently Asked Questions

What is the Model Context Protocol (MCP)?

The Model Context Protocol (MCP) is an open standard that enables seamless integration between language models and external tools. It allows AI assistants to interact with applications and services in a standardized way.

Do I need a TogetherAI account to use this tool?

Only if you want to use the AI image generation feature. If you don't need to generate images, you can use all other features without an API key.

What file formats are supported for images?

The tool supports common image formats including PNG, JPEG, and GIF. For best results, use high-resolution images.

How do I customize the slide layouts?

The tool uses standard PowerPoint slide layouts. You can modify the presentation after generation using PowerPoint or other presentation software.

Can I work with existing presentations?

Yes, you can use the open-presentation tool to open an existing .pptx file, make modifications, and save it with save-presentation.

What chart types are supported?

The tool automatically selects the most appropriate chart type based on your data. Supported types include bar charts, line charts, pie charts, and scatter plots.

Where are my presentations saved?

Presentations are saved to the folder specified with the --folder-path argument when starting the server.
