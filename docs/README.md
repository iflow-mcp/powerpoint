# PowerPoint MCP Server Documentation

This folder contains the documentation for the PowerPoint MCP Server, designed for GitHub Pages.

## Structure

- `index.html`: Main documentation page
- `css/style.css`: Stylesheet for the documentation
- `js/script.js`: JavaScript for navigation enhancements
- `assets/`: Folder for images and other assets (currently empty)

## Deployment

To deploy this documentation to GitHub Pages:

1. Push the changes to the repository
2. Go to the repository settings
3. Navigate to the "Pages" section
4. Set the source to the `docs` folder on the `main` branch
5. Save the settings

The documentation will be available at: https://iflow-mcp.github.io/powerpoint/
